# Issue 002: dev/ directory is gitignored

## Description

The `.gitignore` file includes `dev/` which means the original source script (`dev/vidcrop.py`), the evolution document (`dev/vidcrop5.md`), and the scale reference tool (`dev/vidhwscale.py`) are not tracked in version control.

## Impact

- Source script used for the refactoring is not in the git history
- Reference materials not accessible to other contributors

## Options

1. Remove `dev/` from `.gitignore` and track the files
2. Keep `dev/` ignored but copy important reference files elsewhere
3. Leave as-is (dev files are development artifacts not needed for the package)

## Status

Open — decision needed on whether to track dev/ files
