# AGENTS.md — vexy-vid Development Guide

## Project Overview

`vexy-vid` is a Python CLI tool for high-performance video cropping and trimming. It wraps ffmpeg with automatic detection capabilities (letterbox, subtitles) and hardware-accelerated encoding.

## Architecture

### Package structure

```
src/vexy_vid/
├── __init__.py      # Version import
├── cli.py           # Entry point — fire.Fire({"crop": crop, "trim": trim})
├── constants.py     # All constants (thresholds, pool sizes, encoder lists)
├── utils.py         # Parsing, path generation, video info, caching
├── encoder.py       # Hardware encoder detection + encoding pipeline
├── pipeline.py      # Producer-consumer frame processing with buffer pool
├── frames.py        # Frame extraction (PyAV primary, ffmpeg fallback)
├── analysis.py      # Numba-optimized detection (letterbox, subtitles)
├── crop.py          # `crop` command implementation
└── trim.py          # `trim` command implementation
```

### Data flow

1. CLI (`cli.py`) dispatches to `crop()` or `trim()` via python-fire
2. Command functions parse args, call detection if needed (`analysis.py`)
3. Build ffmpeg filter string (crop, optional scale)
4. `encoder.py` finds best encoder (hardware → software fallback)
5. ffmpeg-python executes the encoding

### Key dependencies

- **fire** — CLI framework (auto-generates help from function signatures)
- **ffmpeg-python** — ffmpeg command builder
- **PyAV** — Fast frame extraction (imported BEFORE cv2)
- **opencv-python** — Image processing for detection
- **numba** — JIT-compiled pixel analysis
- **loguru** — Structured logging
- **rich** — Console status display

## Conventions

### Code style

- **Formatter/linter:** ruff (line-length 100, target py310)
- **Type hints:** Modern Python 3.10+ syntax (`str | None`, not `Optional[str]`)
- **No `typing` imports** — use built-in union syntax
- **Import order:** `import av` before `import cv2` (reduces macOS dylib warnings)

### Build system

- **hatch** + **hatch-vcs** for packaging (version from git tags)
- **uv** for dependency management
- Entry point: `vexy-vid` → `vexy_vid.cli:main`
- Version fallback: `0.0.1` when no git tag exists

### Naming

- CLI commands: `crop` (not clip), `trim`
- Parameters: `--crop` (not --size), `--scale`
- Operation names in output paths: `"crop"`, `"trim"`

### Testing

- Syntax check: `python -m py_compile src/vexy_vid/<module>.py`
- Install test: `uv pip install -e .`
- CLI test: `vexy-vid crop --help` / `vexy-vid trim --help`
- ffmpeg is a system dependency — tests that process video require it

## Gotchas

- PyAV and opencv-python bundle conflicting libavdevice dylibs on macOS (objc warning). Import `av` before `cv2`.
- numba bundles LLVM via llvmlite — no extra system dep needed
- ffmpeg binary is NOT pip-installable — must be installed separately
- The `crop` parameter in `crop()` function shadows the function name — works fine with fire
- `_version.py` is generated by hatch-vcs and gitignored
